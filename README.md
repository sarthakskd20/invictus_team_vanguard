# Invictus Inventory Management System
> **Team Vanguard** | Electrolyte Solutions Hackathon

A full-stack, component-level inventory management system built with the B.L.A.S.T. protocol.

## 🚀 Quick Start

### Prerequisites
- **Node.js** (v18+)
- **PostgreSQL** (v15+) - [Installation Guide](docs/postgresql_setup.md)

### One-Click Setup
Run the automated launcher:
```bash
d:\invictus_hackathon\run_app.bat
```
This script will:
1. Check for required software
2. Install dependencies (frontend & backend)
3. Set up the database (schema + seed data)
4. Start the application
